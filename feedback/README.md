# feedback/

The loops that carry one run's lessons into the next. Not included in this edition.

| File | Written by | Read by | Purpose |
|------|-----------|---------|---------|
| `scout-instructions.md` | Red Team and Strategist | both desks | tomorrow's collection priorities and standing rules |
| `watchlist-ledger.md` | Strategist only | Strategist, oracle, monthly review | the prediction ledger: every dated call, scored against reality |
| `quality-log.md` | Red Team | Red Team (recent entries), monthly review | what each audit found |
| `oracle/<date>.md` | the oracle job | the next Red Team, monthly review | the second-vendor verdict |
| `numeric-lint/`, `tracker-lint/` | deterministic monitors | the next Red Team; the Strategist (tracker flags) | flags, never edits |

Every file here is a monitor, never an optimisation target.
