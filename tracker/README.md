# tracker/

Persistent memory across days. Not included in this edition.

- `threads/<slug>.md`: one file per running story (for example export controls, frontier-AI governance), with a `## Status:` header, a summary, dated entries and "watch for" items.
- `companies/{china,us,korea}/<company>.md`: one file per company (Korean memory makers are tracked by the US Desk).

Written by the Strategist; read by the desks (their own region's companies), the Strategist, the oracle (threads) and the monthly review. A deterministic lint flags thread files whose body contradicts their status header.
