# reports/

The published daily briefings, `reports/YYYY-MM-DD.md`, written by the Red Team + Editor and kept permanently. Not included in this edition.

Each report has a fixed structure: a lead story, Signal items with source-confidence tags and bias notes, the discarded noise with reasons, thread updates, and a Watch List of dated 48–72-hour calls. The calls are graded later for calibration; they are not investment advice.
